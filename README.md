# YouTube to Article Generator

Convert YouTube videos into structured, professional articles and downloadable PDFs using LLMs.

## Features
- Extracts transcript from YouTube
- Generates structured article using Groq LLM
- Converts article into PDF
- Simple Streamlit UI

## Tech Stack
- Python
- Streamlit
- Groq API (LLM)
- YouTube Transcript API
- ReportLab (PDF)

## How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
